Tabela e lista

Duas formas de mostrar muitos itens: a tabela, quando cada coluna é um dado comparável, e a lista com trilha lateral, quando cada linha é um objeto que se abre. A trilha é a assinatura de interação do Apolo — marca onde você está sem pintar a linha inteira.

01Uso

Tabela ou lista: a escolha

Use tabela quandoUse lista com trilha quando
O usuário compara valores entre linhas O usuário escolhe um item para abrir
Cada coluna é um dado do mesmo tipo Cada linha é um objeto com título e metadados
Ordenar por coluna faz sentido A ordem é dada pela fila ou pelo prazo
Exemplo: relatório, conciliação, painel de gestor Exemplo: caixa de entrada, fila de tarefas
Caixa de Entrada4 tarefas

Passe o mouse nas linhas. A trilha lateral aparece à esquerda, o título muda de cor e o chevron desliza 4px. A primeira linha está no estado ativo.

Quando não usar nenhum dos dois

  • Menos de três itens → mostre-os direto, sem cabeçalho de tabela nem moldura de lista.
  • Um item por vez, com muitos detalhes → é uma lista de definição (.zaz-dl), que é o formato de "detalhe de tarefa".
  • Dados que só fazem sentido comparados visualmente → gráfico.

Anatomia da linha de lista, no estado ativo.

1. Trilha lateral (obrigatório)

Borda esquerda de 4px, transparente, que vira roxa no hover e no ativo. É a assinatura de interação do Apolo: foco sem trocar o fundo inteiro. Pintar a linha toda de roxo funcionaria em uma linha e cansaria em trezentas.

A borda existe sempre, mesmo transparente. Se ela só aparecesse no hover, a linha se deslocaria 4px para a direita a cada passada do mouse.

2. Título (obrigatório)

Peso 600, cor de leitura. Identifica o objeto — no Apolo, é o nome do processo mais o documento. Muda para a cor da marca no hover, junto com o chevron: dois sinais para a mesma coisa, porque a trilha sozinha é discreta demais para quem olha rápido.

3. Metadados (opcional)

Segunda linha, 12px, cor de apoio, separados por ponto médio. É onde ficam tempo relativo, grupo, marca parceira. Três informações no máximo — a quarta ninguém lê.

4. Estado (opcional)

Um badge, encostado à direita antes do chevron. Sempre o último conteúdo antes da seta, e sempre um só: dois badges na mesma linha competem e nenhum é lido.

5. Chevron (opcional)

Indica que a linha abre alguma coisa. Desliza 4px para a direita no hover — o movimento sugere a direção para onde a navegação vai. Some quando a linha não é clicável.

Cabeçalho fixo

O <th> é sticky no topo. Numa tabela de 200 linhas, o cabeçalho que some ao rolar obriga a pessoa a voltar para lembrar o que é a terceira coluna.

Densidade

16px de espaço interno por célula. É mais folgado que o mínimo — e é deliberado: a fila do Apolo é lida o dia inteiro, e tabela apertada cansa depois da terceira hora.

Os três estados da linha. Hover está simulado nesta página para poder ser visto parado.

2. Lista vazia

Nunca mostre uma moldura vazia. O estado vazio diz por que está vazio — filtro sem resultado, fila zerada e falta de permissão são três situações diferentes — e oferece a saída quando existe uma.

Nenhuma tarefa encontrada para este filtro.

3. Rolagem e paginação

  • Tabela larga rola no eixo X dentro do próprio container, nunca empurrando a página inteira para o lado.
  • A contagem fica no rodapé do card: "Mostrando 20 de 1.284". Sem ela, ninguém sabe se a lista acabou ou se falta carregar.
  • Sem animação de entrada em item. Em trezentas linhas, entrada animada vira tela tremendo a cada carregamento.

4. Carregando

Mantenha a altura da lista durante o carregamento — com esqueleto ou com a lista anterior esmaecida. Lista que encolhe para zero e volta faz a página inteira pular, e o clique da pessoa acerta o item errado.

5. Tema escuro

O véu do hover nasce de color-mix() sobre o --zaz-primary-text, que já clareia no escuro. Por isso a linha tem uma regra só para os dois temas.

Como usar

Classes e HTML mínimo

Lista com trilha

a linha é <button>, porque abre alguma coisa
<div class="zaz-track">
  <button class="zaz-track__row" type="button" aria-current="true">
    <span class="zaz-track__main">
      <span class="zaz-track__title">Credenciamento VERO</span>
      <span class="zaz-track__meta">há 2h 15m · CSAdquirente</span>
    </span>
    <span class="zaz-badge zaz-badge--warning">Pendência</span>
    <span class="zaz-track__chevron" aria-hidden="true">›</span>
  </button>
</div>

aria-current="true" faz duas coisas ao mesmo tempo: pinta a trilha (o CSS casa com esse atributo) e anuncia ao leitor de tela que este é o item atual. Não use uma classe .ativo em paralelo — seria a mesma informação em dois lugares, e um dos dois vai ficar para trás.

O CSS por trás

css/components.css · trecho real
.zaz-track__row {
  /* a borda existe sempre, mesmo transparente: se ela nascesse no
     hover, a linha inteira pularia 4px a cada passada do mouse */
  border-left: 4px solid transparent;
  border-bottom: 1px solid var(--zaz-border-soft);
  padding: var(--zaz-space-4) var(--zaz-space-5);
}

/* hover e ativo compartilham a mesma regra: a diferença é que um
   é temporário e o outro vem do atributo aria-current */
.zaz-track__row:hover,
.zaz-track__row[aria-current="true"] {
  border-left-color: var(--zaz-primary-text);
  background: var(--zaz-veil);
}
.zaz-track__row:hover .zaz-track__chevron { transform: translateX(4px); }

Acessibilidade em tabela e lista

Meta do sistema: WCAG 2.1 nível AA

Tabela precisa ser tabela

  • Use <table>, <thead>, <th> e <td> de verdade. Uma "tabela" feita de <div> com grid perde a navegação por célula e o anúncio do cabeçalho ao mudar de coluna.
  • <th scope="col"> em cabeçalho de coluna, scope="row" quando a primeira célula nomeia a linha.
  • <caption> ou aria-labelledby dando nome à tabela. "Tabela" sozinho não diz do quê.
  • Não use tabela para layout. Nunca.

A linha clicável é um controle

  • A linha é <button> (abre um painel) ou <a> (navega para outra URL) — nunca uma <div> com onclick, que não recebe foco nem responde ao teclado.
  • Foco visível é obrigatório, e a trilha lateral não é suficiente: 4px de borda colorida não alcançam 3:1 de contraste em toda superfície. Acrescente o contorno do sistema no :focus-visible.
  • Não coloque botões dentro da linha clicável — controle dentro de controle é inalcançável pelo teclado. As ações vão numa coluna à parte, fora do alvo principal.
a trilha marca; o contorno é quem garante o teclado
.zaz-track__row:focus-visible {
  outline: 2px solid var(--zaz-ring);
  outline-offset: -2px;   /* para dentro: a linha encosta na vizinha */
}

Item atual

Use aria-current="true" na linha aberta. É o que diz ao leitor de tela "este é o item em que você está" — a cor da trilha não diz nada para quem não a vê.

Ordenação

  • Cabeçalho ordenável é um <button> dentro do <th>, com aria-sort="ascending|descending|none" no <th>.
  • A seta de ordenação é decorativa (aria-hidden): quem informa é o aria-sort.
  • Depois de ordenar, anuncie o resultado num aria-live="polite": "Ordenado por prazo, crescente".

Listas longas

  • A contagem ("Mostrando 20 de 1.284") precisa estar no DOM, não só visualmente — é como quem não vê sabe que a lista tem continuação.
  • Rolagem infinita sem fim anunciado desorienta: prefira "Carregar mais" com foco indo para o primeiro item novo.
  • Depois de filtrar, anuncie quantos sobraram num aria-live. Sem isso, a lista muda em silêncio.

Estado vazio

O texto do estado vazio é conteúdo, não decoração: precisa estar no DOM e ser anunciado quando substitui uma lista que existia. role="status" resolve.
